Windows 提供独立桌面窗口和托盘，Android 提供系统分享入口及后台传输队列。安卓设备可以独立创建中转站，让手机和平板在电脑关闭时继续互传。

## 主要功能

- **集中整理资料**：共享目录树、整文件夹上传、分类筛选、搜索定位、常用目录与最近打开。
- **跨设备收发**：多文件发送、定向发送、批量保存、整文件夹保存时保留目录结构。
- **先看再保存**：图片缩略图、相册、文本和 PDF 预览；预览内可直接操作文件。媒体预览能力因文件格式和主机而异。
- **保留离线副本**：标记本机已保存文件，从本机文件页打开副本；在文件池查看传输任务进度。
- **管理文件与备份**：重复文件提示、回收站、备份导出、可选密码加密及恢复迁移。
- **校验传输与设备身份**：SHA-256 完整性校验、分块恢复、TLS 加密、证书指纹确认和已配对设备撤销。

## 开始使用

Windows 客户端支持 Windows 10/11 x64；Android 客户端要求 Android 8.0 或更高版本。自行生成 EXE 或 APK，请按 [Windows 构建说明](docs/WINDOWS-BUILD.md) 或 [Android 构建说明](docs/ANDROID-BUILD.md) 操作。

1. **选择文件池主机**：启动 Windows 客户端，或在 Android 客户端中创建本机中转站。文件上传后保存在这台设备上。
2. **连接其他设备**：先连接同一 Wi-Fi 或热点，在主机的“我的设备”中查看二维码、连接地址和配对码。其他设备通过该地址加入，核对完整证书指纹后输入配对码。
3. **添加文件**：进入“文件池”，选择目录后添加文件或文件夹。Android 也可以从其他应用的系统分享菜单发送，并选择目标目录。
4. **浏览与保存**：点击文件名预览，按类型或关键词查找；需要离线使用时保存到本机，也可多选后批量保存或整理。

**所有设备需要加入同一台主机的文件池。** 分别创建多个中转站不会自动合并文件。主机应保持运行并连接网络；Windows 启用托盘常驻后，关闭窗口仍可继续共享，使用托盘中的“退出并停止共享”才会完全退出。

Android 的后台发送和保存由原生任务队列处理，可在应用和系统通知中查看进度。系统省电或后台限制可能暂停任务。使用普通网页上传时，请保持页面在前台。

## 连接方式

| 方式 | 使用条件与范围 |
| --- | --- |
| 局域网 | 设备连接同一 Wi-Fi 或热点且彼此可达，无需互联网。公共网络或校园网的设备隔离可能阻止发现和连接。 |
| 蓝牙 | Android 提供安卓设备间的蓝牙直传；Windows 调用系统蓝牙文件传输工具。两者不是统一的跨平台自定义传输协议。 |
| 跨网络 | 远程模块需要自行配置双方可达的中继；自动跨网连接和 NAT 穿透仍属规划。主机必须在线，单有不同 IP 或局域网地址不能保证跨网可达。详见[不同 IP 网络连接构想](#不同-ip-网络连接构想)。 |

连接失败时，先确认主机正在运行、地址有效，并检查 Windows 防火墙是否允许对应网络中的连接。存在设备隔离时，可换用自己的热点。证书指纹发生变化时，应在主机上重新核对身份后再连接。

## 不同 IP 网络连接构想

**星月池的规划方向：让不同 IP 网络中的设备也能访问同一个文件池。** 例如手机使用移动数据、电脑连接 eduroam 或家庭宽带时，仍通过已绑定的设备身份访问文件池，不要求两端处于同一子网。文件池主机继续保存原件并提供预览、上传和下载。

> **状态说明：以下自动连接方案属于规划，尚未完整实现。** 当前远程模块需要自行配置一个双方都能访问的中继；项目不提供公共中继，也没有自动 NAT 穿透。仅仅两端使用不同 IP、都能访问互联网，或填写对方的局域网地址，都不能保证建立连接。真实校园网、手机流量和家庭网络的可达性仍需部署后实测。现有协议见 [远程连接约定](REMOTE-CONTRACT.md)。

### 连接思路

| 组件 | 职责 |
| --- | --- |
| 文件池主机 | 保存原件、执行访问权限检查，提供目录、预览和传输接口；需保持运行与联网。 |
| 手机、平板或电脑客户端 | 保存已确认的主机身份，发起连接、浏览文件池并按需上传或保存。 |
| 协调服务（规划） | 经认证后登记在线状态、交换连接候选地址，帮助已授权设备寻找对方；不承担文件存储。 |
| 中继服务 | 在无法直连时转发客户端与主机之间的加密数据；双方都主动连接这个可达服务。 |

预期连接流程：

1. **首次绑定**：通过可信渠道交换邀请并核对主设备的完整证书指纹，再完成文件池配对。设备名称和 IP 只用于定位，不能代替身份验证。
2. **尝试直连**：优先检查同一局域网或其他已可达地址；后续再引入成熟的 NAT 穿透方案，尝试建立跨网直连。协调服务返回地址不代表该地址一定可达。
3. **失败回退**：直连超时后，使用已配置且双方可达的中继，继续保留客户端到文件池主机的内层 TLS 和设备权限检查。界面显示“直连”“中继”“正在重连”或“主机离线”。
4. **网络变化后恢复**：重新确认主机身份、权限与连接路径，利用已有任务记录和完整性校验恢复符合条件的传输。地址变化不自动更换信任身份；证书变化应停止连接并提示重新核对。

### 使用条件与安全边界

- **两端都能上网，不代表可以直接互连。** 校园网设备隔离、运营商 NAT、端口或协议限制都可能阻止连接。为覆盖直连失败的情况，需要双方能够访问的公网中继；协调与中继可以由同一台服务器承担，但职责不同。
- **不需要另外安装组网软件是设计目标，公网服务仍有其作用。** 没有可达地址、协调或中继等条件时，程序无法保证任意网络互通。即使服务使用 443 端口，也不意味着其协议一定被校园网允许。
- **通道仅服务于文件池。** 不创建供其他软件使用的通用虚拟局域网，不接管整个设备的网络流量。现有安卓地址检查与桌面连接入口仍需适配，当前不能把 Tailscale 的 `100.64.0.0/10` 虚拟 IPv4 地址当作已经支持的连接方式。
- **原件仍在主设备。** 中继按协议只转发端到端加密的数据，不承担云端文件池或离线代收；它仍能观察连接地址、时间和流量。文件池主机能读取原件，传输加密不等于磁盘加密。
- **已有身份校验继续生效。** 协调服务、中继、发现广播或虚拟 IP 都不能代替证书指纹核验；撤销设备、暂停共享和传输完整性校验须在各条连接路径上保持一致。

### 建议实施顺序

1. **先完善已有中继模式**：统一远程连接入口，改善邀请与绑定、连接状态、错误提示和自动重连；保持现有文件池与配对数据。
2. **再增加可达地址直连与自动选择**：适配手动地址、已保存主机和虚拟网络地址；使用同一套身份校验，在可直连时减少中继流量。
3. **最后研究自动穿透**：结合协调服务与成熟的穿透传输组件，并适配现有文件池协议。STUN 提供的地址信息本身不能让现有 HTTPS/TCP 连接自动穿透所有 NAT。

验证应覆盖直连与中继下的权限一致性、错误证书拒绝、断网恢复、路径切换和原件哈希校验；之后在获得许可的实际 eduroam、家庭网络与手机流量环境中，检查可达性、速度及移动端后台表现。中继可能增加延迟并消耗服务器带宽，不能用本机测试代替这些验证。

参考：[Tailscale 的连接与协调原理](https://tailscale.com/blog/how-tailscale-works)、[直连、中继和防火墙条件](https://tailscale.com/docs/reference/faq/firewall-ports)。本方案借鉴连接思路，不表示已实现或兼容 Tailscale 协议。

## 文件保存与隐私

**退出程序不会自动删除文件池。** 主机离线后，其他设备暂时无法访问它的文件池；已经保存到本机的副本仍可使用。Android 文件池位于应用私有目录，卸载应用或清除应用数据会删除其中的内容，请提前导出备份。

可在应用的文件池备份与迁移入口查看保存位置并导出原件、目录结构和校验清单。迁移设备前先备份，再在目标设备恢复；新设备需重新配对。备份应保存在文件池以外的位置，可选择密码加密。

共享文件可由有权限的已配对设备访问。定向文件仍可由发送者、接收者和文件池主机查看；私人分类只用于整理列表，不会改变访问权限。TLS 保护传输过程，主机能够读取保存在本机的原件。图片预览使用缩略副本，保存原件不会以缩略图替代；预览和播放仍会产生流量。更多说明见 [安全与隐私](SECURITY.md)。
